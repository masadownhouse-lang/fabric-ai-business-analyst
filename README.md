# Fabric AI Business Analyst

## Overview

This project demonstrates how Microsoft Fabric can be used to build an AI-powered Business Analyst capable of performing root cause analysis across Sales, Purchasing, Inventory and Finance data.

The solution combines:

- Microsoft Fabric Lakehouse
- Semantic Models
- Fabric Data Agent
- Fabric IQ Ontology
- AI-assisted KPI analysis

## Business Scenario

A fictional food manufacturing and distribution company called Nordic Foods Group operates in:

- Finland
- Sweden
- Estonia

The company manages:

- Sales
- Purchasing
- Inventory
- Finance

Products have:

- Product categories
- Lot numbers
- Expiry dates
- Full traceability from supplier to customer

## Key Business Questions

The solution should answer questions such as:

- Why did EBITA decrease?
- Why did gross margin decline?
- Why did inventory value increase?
- Which products are at risk of expiry?
- Which customers were impacted by a product recall?

## Planned Architecture

ERP Data
→ Lakehouse
→ Semantic Model
→ Ontology
→ Fabric Data Agent
→ AI Business Analyst

1. Purchase Price Increase
